# Memory Runtime Data

This folder is intentionally kept as a placeholder for local experiments.

The normal runtime location is `$AI_STACK_HOME/memory`, created by:

```bash
./ai-stack init
```

Portfolio/demo content lives under `demo/` and can be copied into the runtime
folders with:

```bash
./ai-stack demo
```

Do not commit private notes, indexed repositories, or generated runtime data
from this folder.
