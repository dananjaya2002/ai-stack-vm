# Demo Mode

Demo mode copies fictional memory and sample code repositories into
`$AI_STACK_HOME/memory`, then runs the indexers.

## Run

```bash
./ai-stack demo
```

## Clean

```bash
./ai-stack demo clean
```

The clean command removes only demo memory and demo code repositories.
