# Examples

Use these examples to validate the stack and demonstrate the project.

## Example Guides

- [Demo mode](demo-mode.md): copy fictional memory and sample repositories into
  runtime folders.
- [Curl examples](curl-examples.md): direct API calls for model, proxy, and
  Agentic RAG endpoints.
- [Open WebUI connections](open-webui-connections.md): configure model and RAG
  connections inside Open WebUI.

## Suggested Demo Flow

```bash
./ai-stack up
./ai-stack dashboard
./ai-stack demo
./ai-stack agentic-rag up
./ai-stack status
```

Then ask the sample questions from [Demo mode](demo-mode.md).
